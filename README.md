# Poke & See

Tiny science toys for kids aged 3 to 5. Poke something, see what happens.

Live at pokeandsee.com. No ads, no accounts, no tracking.

- `index.html`: the home page
- `toys/`: one folder per toy
- `kit/`: shared tokens, styles, fonts, logos and icons
- `docs/`: the brand book and the roadmap
